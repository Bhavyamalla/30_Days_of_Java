# Day 2 - Data Types and Input Handling

## Description

Created a Java program that:

- Reads an integer, a double, and a string from user input.
- Adds the integer input to a predefined integer value.
- Adds the double input to a predefined double value.
- Concatenates the input string with a predefined string.
- Displays the results.

## Concepts Practiced

- Variables and Data Types
- Scanner Class
- Integer Input
- Double Input
- String Input
- Type Handling
- String Concatenation

## Sample Input

```text
12
4.0
is the best place to learn and practice coding!
```

## Sample Output

```text
16
8.0
HackerRank is the best place to learn and practice coding!
```
