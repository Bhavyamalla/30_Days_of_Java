# Day 6 - Loops and Multiplication Table

## Description

Created a Java program that generates the multiplication table of a given number from 1 to 10.

The program:
- Reads an integer input.
- Uses a `for` loop to iterate from 1 to 10.
- Calculates and displays the multiplication results in a formatted output.

## Concepts Practiced

- Loops (`for` loop)
- Iteration
- Arithmetic Operations
- User Input
- BufferedReader
- Output Formatting

## Sample Input

```text
2
```

## Sample Output

```text
2 x 1 = 2
2 x 2 = 4
2 x 3 = 6
2 x 4 = 8
2 x 5 = 10
2 x 6 = 12
2 x 7 = 14
2 x 8 = 16
2 x 9 = 18
2 x 10 = 20
```

## Explanation

The program takes an integer `n` as input and uses a loop to multiply `n` by numbers from 1 to 10.

For input `2`:

```text
2 × 1 = 2
2 × 2 = 4
...
2 × 10 = 20
```

## Key Learning

- Understanding how loops execute repeatedly.
- Using loop variables effectively.
- Generating patterned output.
- Combining loops with arithmetic calculations.
