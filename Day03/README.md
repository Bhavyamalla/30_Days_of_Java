# Day 3 - Operators and Meal Cost Calculation

## Description

Created a Java program that calculates the total meal cost by adding:

- Base meal cost
- Tip percentage
- Tax percentage

The final total cost is rounded to the nearest whole number and displayed as output.

## Concepts Practiced

- Arithmetic Operators
- Percentage Calculations
- Methods
- Parameters and Arguments
- BufferedReader for Input Handling
- Type Conversion
- Math.round()
- Problem Solving

## Formula Used

Tip Amount = Meal Cost × Tip Percentage ÷ 100

Tax Amount = Meal Cost × Tax Percentage ÷ 100

Total Cost = Meal Cost + Tip Amount + Tax Amount

## Sample Input

```text
12.00
20
8
```

## Sample Output

```text
15
```

## Explanation

Meal Cost = 12.00

Tip = 12 × 20% = 2.40

Tax = 12 × 8% = 0.96

Total Cost = 12.00 + 2.40 + 0.96 = 15.36

Rounded Total Cost = 15
