# Day 4 - Conditional Statements (If-Else)

## Description

Created a Java program that determines whether a given number is "Weird" or "Not Weird" based on a set of conditions.

The program:
- Reads an integer input.
- Checks whether the number is odd or even.
- Applies conditional logic using if-else statements.
- Prints the corresponding result.

## Concepts Practiced

- Conditional Statements (if, else if, else)
- Logical Operators
- Relational Operators
- Modulus Operator (%)
- Integer Input
- BufferedReader
- Decision Making in Java

## Rules

- If the number is odd, print `Weird`.
- If the number is even and in the range 2 to 5, print `Not Weird`.
- If the number is even and in the range 6 to 20, print `Weird`.
- If the number is even and greater than 20, print `Not Weird`.

## Sample Input

```text
3
```

## Sample Output

```text
Weird
```

## Sample Input

```text
24
```

## Sample Output

```text
Not Weird
```

## Explanation

For input `3`:
- 3 is odd.
- Therefore, the output is `Weird`.

For input `24`:
- 24 is even and greater than 20.
- Therefore, the output is `Not Weird`.
